---

## 🚀 What This Project Does

A **multi-agent AI system with full observability** — every agent action is traced, logged, and visualized on a dashboard.

Built as Stage 9 of an 11-stage AI Engineering roadmap.

---

## ⚙️ Tech Stack

| Layer | Technology |
|---|---|
| **Language** | Python 3.11 |
| **LLM** | Ollama llama3.1 (local) |
| **Tracing** | Custom tracer + JSON storage |
| **Dashboard** | HTML observability dashboard |
| **Token Counting** | Custom token counter |

---

## ✅ Features

- 📊 **Full tracing** — every agent action recorded with timestamps
- 💰 **Token counter** — tracks token usage per request
- 🗄️ **Trace storage** — JSON-based trace persistence
- 📈 **Dashboard** — visual overview of agent performance
- 👥 **Multi-agent pipeline** — Supervisor, Researcher, Analyst, Writer

---

## 🚀 Run Locally

```bash
git clone https://github.com/tahirAliicodes/AgenticAI-Stage9.git
cd AgenticAI-Stage9
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
